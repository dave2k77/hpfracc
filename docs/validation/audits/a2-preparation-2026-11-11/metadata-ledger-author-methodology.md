## What the algebra actually covers

`a2_model.py` uses annotated symbolic terms rather than future IEEE bytes or
made-up process measurements. A raw-array term has exact dtype/shape byte count,
hex length `2*nbytes`, and a digest expression referring to those raw bytes. An
exact payload has the frozen shape and a constrained rational-vector term. A
canonical rational's five nodes are value-independent; its variable length is
not artificially restricted to eight hex digits.

For k exact rationals, canonical array-value length is

```text
2 + max(0,k-1) + k*len(canonical({"num":"","den":""})) + H
H = sum(length(num) + length(den))
2*k <= H <= (8193+8192)*k
```

The upper interval follows the actual 32,768-bit normalized cap and optional
numerator minus sign. Canonical form, reduction, actual scientific computation,
and simultaneous attainability remain **conditions**, not fabricated values.
No arbitrary 2 MiB ancillary bucket is used.

computes depth with root depth 1. A sum across files is not a per-record limit.
